# 考前总结

## 1. 指针指向函数

加括号，形如：

```c
int (*p)(int x, int y)
```

## 2. 指向数组的指针与指针数组

- 指针指向数组：`int (*p)[5]`
  - 步长：int (*p)[4]; int[4] (16 字节) 16 字节 下一辆包含 4 个元素的**"一整行"**的首地址
- 指针数组：`int *p[5]`

## 3. argc/argv

### argc（Argument Count）—— 参数计数器

- 本质：一个整型（int）变量
- 作用：记录命令行中输入的字符串总个数
- ⭐ 黄金铁律：程序名（或可执行文件名）本身也会被算作第一个参数！

### argv（Argument Vector）—— 参数字符串数组

- 本质：一个字符指针数组（即字符串数组），每个元素指向一个命令行参数字符串
- 结构：
  - `argv[0]` 指向程序名字符串（如 "file.exe"）
  - `argv[1]` 指向第一个附加参数（如 "China"）
  - `argv[2]` 指向第二个附加参数（如 "Beijing"）


## 4. 结构体

### 4.1 结构体变量的声明、定义与内存分配

- **核心概念：** 结构体类型本身（如 struct abc）只是一个”设计蓝图”，不占用任何实际内存空间。因此，绝对不能直接通过类型名去访问或修改成员。
- **避坑必看：** 必须先用蓝图实例化出具体的变量，才能分配内存并使用。

结构体定义与变量声明示范：

```c
struct abc {
    int a;
    int b;
    int c;
}; // ⚠️ 注意：大括号后面的分号绝对不能丢！

// ❌ 错误语法（考卷高频陷阱）：
// abc.a = 1; （不能直接用类型名访问成员）

// 🌟 正确语法：
struct abc x; // 实例化出具体变量 x
x.a = 1;      // 必须通过【变量名.成员名】来正常读写
```

### 4.2 整体赋值与比较规则

- **允许整体赋值：** 如果两个结构体变量的类型完全相同，可以互相直接赋值，这在底层属于整块内存的快速拷贝。
- **禁止整体比较：** C 语言规定，结构体变量之间不能直接使用 == 或 != 运算符进行整体关系判断。

代码逻辑展示：

```c
struct abc x = {1, 2, 3};
struct abc y;

y = x; // 100% 合法：y 内部的 a, b, c 瞬间变得和 x 一模一样

// ❌ 编译报错：
// if (x == y)

// 🌟 正确做法：必须手动逐个成员进行对比
if (x.a == y.a && x.b == y.b && x.c == y.c) {
    // 满足条件后的操作
}
```

### 4.3 结构体数组（群体排序与查表）

#### 数据整体交换

在应对期末大题（如”学生成绩排序”、”按数字和排序”）时，一旦满足了交换条件，必须整体交换结构体数组中的元素，千万不能只交换其中的某一个成员，否则会导致数据逻辑错乱。

冒泡排序核心片段（按成绩从小到大排序）：

```c
struct Student {
    int id;
    int score;
};

struct Student stu[10]; // 定义一个包含10个学生的结构体数组
struct Student temp;    // 定义一个同类型的结构体变量作为中间中转

for (int i = 0; i < 9; i++) {
    for (int j = 0; j < 9 - i; j++) {
        if (stu[j].score > stu[j+1].score) {
            // 🌟 整个结构体变量打包交换，内部所有数据同步移动
            temp = stu[j];
            stu[j] = stu[j+1];
            stu[j+1] = temp;
        }
    }
}
```

#### 群体最值查找

常用于”找出最高分学生”或”找出性能最强的传感器”等业务逻辑。

```c
int max_idx = 0; // 默认假设下标为 0 的个体最值最大
for (int i = 1; i < 10; i++) {
    if (stu[i].score > stu[max_idx].score) {
        max_idx = i; // 仅记录最高分所在的数组下标，避免频繁拷贝数据
    }
}
// 循环结束后，统一提取并打印最强个体
printf(“最高分学生ID: %d, 成绩: %d”, stu[max_idx].id, stu[max_idx].score);
```

### 4.4 结构体指针（高效内存桥梁）

#### 成员访问符的使用准则：`. 还是 ->`

- 使用结构体变量名访问数组成员时，用点运算符 `.`
- 使用结构体指针名访问数组成员时，用箭头运算符 `->`

核心写法对照：

```c
struct abc x = {1, 2, 3};
struct abc *p = &x; // 定义指针 p，直接指向结构体变量 x 的首地址

// 以下三种成员修改写法完全等价：
x.a = 10;     // 变量名用点 '.'
p->a = 10;    // 🌟 指针名用箭头 '->'（期末最爱考、也最常用）
(*p).a = 10;  // 较少使用，注意 *p 必须用小括号括起来
```

#### 函数传参的效率陷阱（传值 vs 传地址）

结构体通常包含多个成员，占用内存较大。为了节约系统开销并实现数据的有效修改，强烈推荐使用传地址（指针）。

函数定义与调用对比：

```c
// ❌ 方式 A：传值调用
// 系统会完整复印一份庞大的结构体副本送进函数，极其消耗内存，且在函数内修改副本，原件毫无变化。
void wrong_modify(struct abc tmp) {
    tmp.a = 100;
}

// 🌟 方式 B：传指针调用（推荐）
// 无论结构体多大，只需要传递 4 或 8 字节的指针地址，运行极快。且能在函数内【远程修改】主函数中的原件。
void right_modify(struct abc *p) {
    p->a = 100; // 成功篡改/校准主函数中的实体数据
}
```

### 4.5 内存对齐机制（选择题陷阱）

- **核心结论：** 结构体变量在内存中所占用的总存储空间，并不是各个成员所占字节数的简单相加。如果在选择题中看到”结构体总大小等于各成员大小之和”的说法，直接排除！
- **对齐法则：** 为了方便 CPU 高效读取，结构体的实际总大小必须是其内部”最大基本数据类型成员”所占字节数的整数倍。编译器会在较小的成员后面自动填充空白的字节空隙，以此实现内存对齐。

## 5. 其他要点

### 5.1 动态内存分配

动态分配失败时，`malloc()` 函数返回 NULL

### 5.2 运算符优先级

初等第零、单目第一、算术第二、关系第三、逻辑第四、赋值第五、逗号最底

- 初等：（）{} [] .
- 从右向左：单目、三目（?:）、赋值

### 5.3 变量与数组初始化

- 若静态局部变量未赋初值，则其默认值为 0
- 形参数组的长度在实际调用时不需要
- 定义 `char str[5] = "Hello";` 是错的，因要形成字符串最后要有 `\0`，而它没空间给 `\0`
- 若定义 `int a[5] = {1,2,3};`，则 `a[3]` 的值是 0

### 5.4 循环中的自增

for 循环第三个语句的自增在 for 程序的最后进行；while 循环的自增出现在条件判断中，则在判断完就自增了，因此自增相当于出现在 for 的第二个语句里面。if 条件判断同理 while。

### 5.5 void 的理解

void 相当于向主函数"借一些值"，然后把借的东西复制一份副本，用做运算和行为、输出，原件还回去，副本销毁。

#### 冒泡排序

对大小为 N 的整型数组 a 进行从小到大排序：

```c
void bubble_sort(int a[], int n)
{
    int i, j, temp;
    for (i = 0; i < n - 1; i++) {         // 外层循环控制轮数
        for (j = 0; j < n - 1 - i; j++) { // 内层循环进行两两比较
            if (a[j] > a[j + 1]) {        // 如果前面的比后面大，则交换
                temp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = temp;
            }
        }
    }
}
```

#### 斐波那契数列

输出斐波那契数列的前 N 项：

```c
void print_fib(int n)
{
    long long f1 = 1, f2 = 1, f3; // 预防数据过大用 long long
    int i;
    printf("%lld %lld ", f1, f2);
    for (i = 3; i <= n; i++) {
        f3 = f1 + f2;
        printf("%lld ", f3);
        f1 = f2; // 滚动更新
        f2 = f3;
    }
}
```

#### 字符串拼接（手写 strcat）

将字符串 src 拼接到 dest 的后面：

```c
void my_strcat(char *dest, const char *src)
{
    // 1. 先让指针移动到 dest 的末尾（找到 '\0'）
    while (*dest != '\0') {
        dest++;
    }
    // 2. 将 src 的内容逐个复制到 dest 后面，直到遇到 src 的 '\0'
    while (*src != '\0') {
        *dest = *src;
        dest++;
        src++;
    }
    *dest = '\0'; // 【千万别忘】最后一定要手动补上字符串结束符！
}
```

#### 二维数组找最小值

找出 4 行 5 列二维数组中的最小值并打印坐标：

```c
void find_min(int matrix[4][5])
{
    int min = matrix[0][0];
    int i, j;

    // 第一步：先找出真正的最小值
    for (i = 0; i < 4; i++) {
        for (j = 0; j < 5; j++) {
            if (matrix[i][j] < min) {
                min = matrix[i][j];
            }
        }
    }

    // 第二步：遍历打印所有等于该最小值的坐标（防止有并列最小值）
    for (i = 0; i < 4; i++) {
        for (j = 0; j < 5; j++) {
            if (matrix[i][j] == min) {
                printf("min:%d---row:%d,col:%d\n", min, i, j);
            }
        }
    }
}
```

#### 某日期是这一年的第多少天
```c
#include <stdio.h>

// 核心算法函数
int get_day_of_year(int year, int month, int day) {
    // 1. 定义平年 12 个月的天数表（第 0 个元素放 0，方便下标对齐 1-12 月）
    int days_of_month[] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
    int total_days = 0;

    // 2. 如果是闰年，把 2 月的天数手动修正为 29 天
    if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)) {
        days_of_month[2] = 29;
    }

    // 3. 累加过去所有整月的天数
    // ⚠️ 注意：循环条件是 i < month，不能包含当前月
    for (int i = 1; i < month; i++) {
        total_days += days_of_month[i];
    }

    // 4. 加上当前月过去的不满整月的天数
    total_days += day;

    return total_days;
}

// 考试 main 函数调用示范
int main() {
    int y = 2026, m = 5, d = 29;
    int result = get_day_of_year(y, m, d);
    printf("%d年%d月%d日是该年的第 %d 天\n", y, m, d, result);
    return 0;
}
```
