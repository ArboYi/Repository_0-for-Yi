# Claude Code 使用指南与常用快捷键

适用于：macOS / Linux 终端环境

---

# =========================
# 一、启动与基础对话
# =========================

## 启动 Claude Code
在终端中进入项目目录后直接运行：
claude

## 启动时指定模型
claude --model claude-sonnet-4-6

## 继续上次对话
claude --continue

# =========================
# 四、权限控制
# =========================

## 权限模式
Claude Code 有三种权限模式：
- **自动允许（allow）**：直接执行，无需确认
- **询问（ask）**：每次执行前询问
- **拒绝（deny）**：不允许执行

## 添加权限
/add-permission   # 为指定工具添加权限

## 管理权限文件
~/.claude/settings.json        # 用户级设置
.claude/settings.json          # 项目级设置
.claude/settings.local.json    # 本地设置（不提交到 git）

# =========================
# 五、使用技巧
# =========================

## 1. 善用 CLAUDE.md
在项目根目录放置 CLAUDE.md 文件，写入项目说明、约定、常用命令等。
Claude 每次启动会自动读取，帮助它理解你的项目。

示例内容：
# 项目简介
这是一个机器人控制系统的 C 语言项目。

# 构建命令
make build     # 编译
make test      # 运行测试
make flash     # 烧录到开发板

# 代码风格
- 使用 C99 标准
- 函数名用 snake_case
- 全局变量前缀 g_

## 2. 计划模式（Plan Mode）
复杂任务先用 /plan 进入计划模式，让 Claude 先设计方案，
你确认后再开始写代码，避免走弯路。

## 3. 压缩上下文
对话太长时可以 /compact，将之前的对话压缩成摘要，
释放 token 空间，让模型继续高效工作。

## 4. 让 Claude 自己做验证
写完代码后可以要求：
"请验证你的改动是否正确，运行相关测试"

## 5. 明确指定范围
"只修改 src/controller.c 中的 pid_tuning 函数"
比 "帮我优化代码" 更精确，结果更可控。

# =========================
# 六、常见工作流
# =========================

## 工作流 1：修复 Bug
1. 描述 bug 现象
2. Claude 搜索相关代码
3. Claude 分析原因并提出修复方案
4. 确认后 Claude 直接修改代码
5. 运行测试验证

## 工作流 2：新增功能
1. 描述需求
2. /plan 先出方案
3. 确认方案后开始实现
4. Claude 写代码 + 测试
5. 提交到 git

## 工作流 3：代码审查
1. 在分支上完成开发
2. /review 让 Claude 审查整个 PR
3. 根据建议修改
4. 推送并创建 PR 到 GitHub

# =========================
# 七、Git 集成
# =========================

Claude Code 可以直接操作 git：
- git status / git diff 查看改动
- git add + git commit 提交代码
- gh pr create 创建 Pull Request

**注意**：Claude 只在被明确要求时才会提交代码，
不会主动修改你的 git 历史。
