# 指针与内存

## 一句话理解

指针就是一个**存放地址的变量**。普通变量存值，指针存的是"那个值在哪里"。

---

## 核心语法速查

```c
int x = 10;       // 普通变量，x 的值是 10
int *p = &x;      // p 是指针，存的是 x 的地址

printf("%d", x);   // 10    — 直接取值
printf("%p", &x);  // 0x... — x 的地址
printf("%d", *p);  // 10    — 通过指针取值（解引用）
printf("%d", p);   // 错误   — p 是地址，别用 %d 打印
```

| 符号 | 含义 | 用在哪 |
|------|------|--------|
| `int *p` | 声明 p 是指针类型 | 定义变量时 |
| `&x` | 取 x 的地址 | 赋值给指针时 |
| `*p` | 解引用，取 p 指向的值 | 读写指向的数据时 |

---

## 为什么用指针

**三个核心场景：**

### 1. 在函数里修改外部变量
```c
// ❌ 不行：只是改了副本
void add(int n) { n = n + 1; }

// ✅ 传地址进去改
void add(int *p) { *p = *p + 1; }

int a = 5;
add(&a);  // a 变成 6
```

### 2. 操作数组和字符串
```c
char str[] = "hello";
char *p = str;        // p 指向 str 第一个字符

while (*p != '\0') {  // 遍历直到字符串结束
    printf("%c", *p);
    p++;              // 指针后移一个字符
}
```

### 3. 动态分配内存
```c
int *arr = (int *)malloc(10 * sizeof(int));  // 申请 10 个 int
arr[0] = 42;
free(arr);  // 用完一定要释放
```

## 常见坑

### 坑 1：未初始化的野指针
```c
int *p;        // 危险！p 指向随机地址
*p = 10;       // 可能崩溃
// 正确做法：
int *p = NULL; // 或者 int *p = &某个变量;
```

### 坑 2：数组越界
```c
int a[5];
int *p = a;
p = p + 10;    // 越界！p 指向了不属于你的内存
```

### 坑 3：返回局部变量的地址
```c
int* bad() {
    int x = 10;
    return &x;  // ❌ x 在函数返回后就销毁了
}
```

### 坑 4：指针与数组的混淆
```c
char *s1 = "hello";   // 字符串常量，不可修改
char s2[] = "hello";  // 字符数组，可以修改

s1[0] = 'H';  // ❌ 崩溃
s2[0] = 'H';  // ✅ 正常
```

## 结合你的代码理解

你写的 `PointerHomeworkForGittest.c` 就是一个典型的指针操作字符串的例子：

```c
char *p;
p = a;                    // p 指向数组 a 的首地址
for (count = 0; *p != '\0'; count++) p++;  // 遍历统计长度
p += n - 1;               // 指针跳到第 n 个字符
for (; *p != '\0'; p++)   // 从第 n 个字符开始复制
    b[i++] = *p;
```

拆解：
- `p = a` → p 指向 a[0]
- `*p != '\0'` → 判断是否到了字符串末尾
- `p++` → 指针移动，指向下一个字符
- `p += n-1` → 直接跳过 n-1 个字符，等效于 `p = &a[n-1]`
- `*p` → 取出当前指向的字符
- `b[i++] = *p` → 把字符复制到 b 数组，i 后移

## 指针与数组的关系

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;  // p 指向 a[0]，等价于 int *p = &a[0]

// 以下几种写法完全等价
a[2]     == 20
*(a+2)   == 20
*(p+2)   == 20
p[2]     == 20    // 指针也能用下标

// 但指针可以做这件事，数组名不行
p++;  // ✅ p 指向下一个元素
a++;  // ❌ 编译错误，数组名是常量不能自增
```

---

## 指针的指针（二级指针）

```c
int x = 10;
int *p = &x;    // p 存 x 的地址
int **pp = &p;  // pp 存 p 的地址

**pp = 20;      // 通过两级解引用修改 x
// **pp = *(*(pp)) = *(p) = x = 20
```
